ONGOING PROJECT

ATLAS

Adaptive Technology for Location and Spatial Support: An intelligent, low-cost wearable navigation system designed to provide real-time obstacle awareness and directional guidance to visually impaired individuals.

PROJECT

Abstract

ATLAS (Adaptive Technology for Location and Spatial Support) is an assistive wearable navigation system designed to improve independent mobility for visually impaired individuals. The system combines computer vision and depth sensing to provide real-time environmental awareness without depending on pre-built maps, cloud services, or expensive depth-sensing hardware. Using two VL53L5CX multizone Time-of-Flight (ToF) sensors, ATLAS generates an 8×16 depth matrix with a 90-degree field of view to identify structural hazards such as stairs, drop-offs, and walls. A USB camera connected to a Raspberry Pi 5 runs YOLOv8 for real-time semantic obstacle detection, identifying objects such as people, cars, and chairs. A spatial fusion engine combines visual object detection with depth information to estimate both obstacle identity and distance. The system delivers contextual audio alerts and directional guidance, functioning as a digital "guide dog" to support safer and more independent navigation.

RESEARCH MOTIVATION

The Problem

How can we build an intelligent, low-cost wearable navigation system that delivers real-time obstacle awareness and directional guidance to visually impaired individuals without pre-built maps, cloud dependency, or expensive depth hardware? Existing navigation approaches can face limitations in providing detailed real-time spatial awareness of nearby obstacles and environmental hazards. ATLAS aims to address this challenge through multimodal sensing, computer vision, and real-time spatial understanding.

SYSTEM ARCHITECTURE

Core Integrations

ATLAS integrates depth sensing, visual intelligence, spatial processing, and audio feedback into a unified wearable navigation system.

01. Dual Time-of-Flight (ToF) Depth Matrix

The system uses two VL53L5CX multizone Time-of-Flight sensors operating on dual I2C buses. Their depth measurements are combined to generate a seamless 8×16 depth matrix with a 90-degree field of view. This enables the detection of structural hazards such as stairs, drop-offs, and walls.

02. Real-Time Semantic AI (YOLOv8)

A USB camera provides visual input to a lightweight YOLOv8 neural network running on a Raspberry Pi 5. The model identifies surrounding objects and obstacles, including people, cars, and chairs, in real time. This provides semantic information about the user's surrounding environment.

03. Spatial Fusion Engine

The spatial fusion engine combines visual information from YOLOv8 with depth measurements from the ToF sensors. It overlays 2D AI bounding boxes onto the 3D ToF depth matrix. This creates geometry-aware semantic mapping, allowing the system to understand both what an obstacle is and how far away it is.

04. Multi-Modal Audio Feedback

ATLAS provides contextual audio alerts and voice instructions to communicate environmental information to the user. The system uses eSpeak-NG for natural voice guidance and a speaker module with a MAX98357A amplifier to generate audio cues. For example, the system can provide an alert: "Caution! Person very close, 12cm ahead." These audio instructions help users understand nearby obstacles and navigate their surroundings.

TECHNOLOGY

Technology Stack

The system brings together embedded hardware, computer vision, depth sensing, spatial processing, and audio technologies.

Hardware: Raspberry Pi 5, Dual VL53L5CX ToF Sensors, USB Camera, MAX98357A Amplifier and Speaker.

AI and Computer Vision: YOLOv8, Real-Time Object Detection, Semantic Mapping and Spatial Fusion.

Embedded Systems: Python, Dual I2C Communication, Sensor Integration and Real-Time Processing.

Audio: eSpeak-NG, Voice Guidance and Contextual Audio Alerts.
